# Portfolio Collection

This repository contains a landing page linking to two static portfolios:

- `farid/` — Farid Ilhamsyah
- `lalu-klampan/` — Lalu Klampan

## Deploy to GitHub Pages

1. In the repository settings, open **Pages** and set **Source** to **GitHub Actions**.
2. Push changes to `main`, or run **Deploy static site to GitHub Pages** manually from the **Actions** tab.
3. Open the Pages URL shown in the workflow run or under **Settings → Pages**.

The workflow uses the official GitHub Pages actions and requires the repository's Actions workflow permissions to allow the configured Pages deployment permissions. No secrets are required.
